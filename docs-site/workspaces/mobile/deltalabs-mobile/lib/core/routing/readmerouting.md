# lib/core/routing/

Navigation and route management using **go\_router**.

## app\_routes.dart

All route path constants in one place:

```dart
AppRoutes.login           // '/auth/login'
AppRoutes.home            // '/home'
AppRoutes.registerStep1   // '/auth/register/step1'
// etc.
```

Never hardcode route strings — always use these constants.

## app\_router.dart

`appRouterProvider` — a Riverpod provider that creates and returns the `GoRouter` instance.

Key behaviors:

-   **Watches** `authProvider` — router rebuilds whenever auth state changes
    
-   `initialLocation` — set from `initialAppRoute` in `bootstrap.dart` (determined before `runApp` by reading local token — no flash)
    
-   `redirect` — guards every navigation:
    
    -   Logged-in user on auth screen → `/home`
        
    -   Unauthenticated user on protected screen → `/auth/login`
        
    -   While auth is loading → no redirect (initial route already correct)
