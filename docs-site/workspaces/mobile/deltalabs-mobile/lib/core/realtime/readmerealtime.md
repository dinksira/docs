# lib/core/realtime/

WebSocket connection for real-time features (live classes, chat, notifications).

## websocket\_manager.dart

`WebSocketManager` — manages the WebSocket lifecycle:

-   Connects to `wsBaseUrl` from `AppConfig`
    
-   Handles reconnection on disconnect
    
-   Exposes a stream of `RealtimeEvent` objects
    

## realtime\_event.dart

`RealtimeEvent` — sealed class representing all possible real-time events:

-   `NewMessage` — chat message received
    
-   `ClassStarted` — live class began
    
-   `NotificationReceived` — push notification
    
-   etc.
